# MLR_code
# Multiple Linear Regression – Startup Profit Prediction

## 📌 Project Overview

This project implements a **Multiple Linear Regression (MLR)** model to predict the **profit of a startup** based on its R&D spending, administration expenses, marketing spending, and geographical state.

The project demonstrates an end-to-end machine learning workflow, including:

* Data loading and preprocessing
* Categorical variable encoding
* Feature and target selection
* Train-test split
* Multiple Linear Regression model training
* Model evaluation using **R² Score** and **Root Mean Squared Error (RMSE)**
* Making predictions on new data
* Saving and loading the trained model using **Pickle**
* Deploying the model through a **Flask web application**

---

## 📊 Dataset

The project uses the **50 Startups dataset**, containing information about 50 startups.

### Features

| Feature           | Description                              |
| ----------------- | ---------------------------------------- |
| `R&D Spend`       | Amount spent on research and development |
| `Administration`  | Administrative expenditure               |
| `Marketing Spend` | Marketing expenditure                    |
| `State`           | State in which the startup operates      |
| `Profit`          | Profit generated by the startup          |

The dataset contains **50 records and 5 columns**.

### Target Variable

**Profit**

The objective is to predict startup profit using the available business expenditure and location-related features.

---

## 🧠 Machine Learning Approach

### 1. Data Loading

The dataset is loaded using Pandas:

```python
self.data = pd.read_csv(self.path)
```

### 2. Categorical Data Encoding

The `State` column is converted into numerical values:

```python
self.data["State"] = self.data["State"].map({
    'New York': 0,
    'California': 1,
    'Florida': 3
}).astype(int)
```

### 3. Feature and Target Selection

The independent variables are separated from the dependent variable:

```python
self.X = self.data.iloc[:, :-1]
self.y = self.data.iloc[:, -1]
```

Where:

**Independent Variables (X):**

* R&D Spend
* Administration
* Marketing Spend
* State

**Dependent Variable (y):**

* Profit

### 4. Train-Test Split

The dataset is divided into training and testing datasets using an **80:20 split**:

```python
train_test_split(
    self.X,
    self.y,
    test_size=0.2,
    random_state=42
)
```

This results in:

* **40 training observations**
* **10 testing observations**

---

## 📈 Model Training

The project uses Scikit-learn's `LinearRegression` algorithm:

```python
self.reg = LinearRegression()
self.reg.fit(self.X_train, self.y_train)
```

The model learns the relationship between startup expenditure variables and profit.

The general form of the model is:

**Profit = β₀ + β₁(R&D Spend) + β₂(Administration) + β₃(Marketing Spend) + β₄(State)**

---

## 📊 Model Evaluation

Two evaluation metrics are used:

### R² Score

R² measures how well the model explains the variation in the target variable.

### Root Mean Squared Error (RMSE)

RMSE measures the average magnitude of prediction errors in the same units as the target variable.

Based on the implementation and dataset:

| Metric   | Training | Testing |
| -------- | -------: | ------: |
| R² Score |   ~0.954 |  ~0.899 |
| RMSE     |   ~8,929 |  ~9,051 |

The testing R² of approximately **0.899** indicates that the model explains a substantial portion of the variation in startup profits on the held-out test data.

The evaluation is implemented directly in `main.py` using `r2_score` and `root_mean_squared_error`.

## 🔮 Custom Prediction

The project also allows predictions for new startup investment values.

Example input:

```python
rd = 1200
admin = 1800
ms = 1900
s = 1
```

These values are passed to the trained regression model:

```python
self.reg.predict([[rd, admin, ms, s]])
```

This demonstrates how the trained model can be used to generate predictions for previously unseen input data.

---

## 💾 Model Serialization

After training, the model is saved using Python's `pickle` library:

```python
with open('model.pkl', 'wb') as file:
    pickle.dump(self.reg, file)
```

The saved model can subsequently be loaded without retraining:

```python
with open('model.pkl', 'rb') as t:
    loaded_model = pickle.load(t)
```

This creates a reusable machine learning model that can be integrated into an application.

---

## 🌐 Flask Web Application

The project includes a Flask backend that loads the trained `model.pkl` file and provides a prediction endpoint.

The Flask application:

1. Loads the trained model.
2. Displays the prediction interface.
3. Accepts user input.
4. Converts the input values into numerical values.
5. Sends the values to the trained model.
6. Returns the predicted startup profit.

The prediction route is implemented using:

```python
@app.route("/predict", methods=['GET','POST'])
```

and the submitted values are passed to the model for prediction.
